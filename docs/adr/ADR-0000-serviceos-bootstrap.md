# ADR-0000 — ServiceOS Bootstrap Architecture

**Status:** Accepted
**Date:** 2026-08-31

## Decision

Establish ServiceOS as a business-service execution control plane and freeze v1.0 for implementation under repository-resident governance.

ServiceOS is horizontally reusable infrastructure plus versioned vertical service packages.

Construction subcontractor/vendor compliance is the first commercial proving vertical.

## Consequences

The horizontal core must remain domain-neutral. Vertical packages provide domain meaning. AI execution is delegated to Zeck.
